# BioRing

Site demonstrativo de um conceito acadêmico de anel inteligente para acompanhamento de sinais de bem-estar.

## Conteúdo
- `index.html`: site responsivo, com modelo conceitual interativo, explicação dos componentes e demonstração fictícia do aplicativo.
- Componentes apresentados: sensor óptico PPG, sensor de temperatura da pele, acelerômetro, circuito com Bluetooth Low Energy, bateria recarregável e contatos de recarga.

## Executar localmente
Abra `index.html` em um navegador. As fontes são carregadas do Google Fonts; o restante da interface é implementado no próprio arquivo.

## Observação
O BioRing é um conceito ilustrativo, não um dispositivo médico nem um projeto eletrônico pronto para fabricação. Os dados exibidos na demonstração são fictícios.
